# Machine Learning Projects

This folder contains Python-based machine learning projects focused on
data preprocessing, classification, model training, and model evaluation.

These projects were developed in Google Colab using Python and
scikit-learn.

## Projects

### 💳 Credit Card Churn Prediction

Developed a logistic regression classification model to predict customer
attrition for a credit card company.

The project includes missing-value handling, data preparation,
train-test splitting, model training, hyperparameter adjustment,
and model evaluation.

**Tools:** Python, Pandas, NumPy, scikit-learn, Logistic Regression

[Explore Credit Card Churn Prediction →](https://github.com/Jeff-Flores/Data-Analytics-Portfolio/blob/main/Machine-Learning-Projects/Credit_card_churn_prediction.ipynb)


### 🩺 Liver Disease Classification

Developed and compared multiple machine learning classification models
to predict liver disease stage using patient characteristics.

The project includes missing-value imputation, categorical encoding,
feature scaling, model training, and performance comparison across
multiple algorithms.

**Models:** Logistic Regression, K-Nearest Neighbors, Random Forest,
Support Vector Classifier

**Tools:** Python, Pandas, NumPy, scikit-learn, Matplotlib

[Explore Liver Disease Classification →](https://github.com/Jeff-Flores/Data-Analytics-Portfolio/blob/main/Machine-Learning-Projects/Liver_disease_classification.ipynb)
