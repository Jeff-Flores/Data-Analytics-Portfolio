# Regression Modeling and Variable Selection

## Project Overview

This project applies regression techniques to two separate datasets.

Study 1 uses simple linear regression to examine the relationship
between fire damage and distance from the nearest fire station.

Study 2 uses multiple linear regression to examine factors associated
with executive salary and applies model-selection techniques to identify
the strongest predictors.

## Tools

- R
- ggplot2
- car
- Simple Linear Regression
- Multiple Linear Regression
- Variable Selection
- VIF Analysis
- Regression Diagnostics

## Study 1: Fire Damage Analysis

A simple linear regression model was used to examine whether distance
from the nearest fire station was associated with fire damage.

The model showed a strong positive relationship between distance and damage,
with an R-squared of approximately 92%.

## Study 2: Executive Salary Analysis

A multiple regression model was built using 10 potential predictors.

Backward selection, forward selection, and stepwise selection were used
to refine the model.

The final model retained five predictors:

- Experience
- Education
- Bonus Eligibility
- Employees Supervised
- Corporate Assets
